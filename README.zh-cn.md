# Plugin Engine

一个基于 PySide6 的桌面插件引擎。你可以把功能做成一个个独立的插件，丢进程序里就能用，不需要改动主程序。

## 它是什么

Plugin Engine 是一个"宿主 + 插件"结构的桌面应用框架。主程序负责承载界面，各种功能都以插件的形式存在，放进插件目录即插即用。适合想把多个小工具、小模块整合到一个统一界面里的场景。

## 核心功能

- **插件化扩展**：每个功能是一个独立插件包，放入 `plugin/` 目录即可，主程序启动时自动加载，无需修改主程序。
- **即插即用的界面**：插件加载后自动成为独立页面，并出现在侧边栏导航中，点一下就能切换。
- **主程序与插件通信**：主程序会向插件下发语言、全局设置和工具方法，并通知插件初始化界面，插件可以随时响应。
- **插件数据读写**：插件可读写统一格式的数据文件，实现数据的持久化和跨插件共享。
- **细粒度权限控制**：每个数据文件可单独声明哪些插件允许读、哪些允许写，越权访问会被直接拒绝。
- **国际化**：内置中英双语界面，插件也可以注册自己的语言包，跟随主程序语言自动切换。
- **声明式设置页**：通过配置即可声明设置项（下拉框、滑块、颜色选择等），自动生成设置界面并自动保存，无需手写控件。
- **自动初始化**：首次运行自动创建插件、数据、日志等目录，无需手动搭建环境。
- **内置日志**：自动记录运行和错误日志，出问题有迹可循。

## 快速开始

```bash
cd .src
pip install PySide6
python main.py
```

首次运行自动生成目录，把插件 zip 放进 `plugin/` 即可加载。
