# 插件开发

## 插件包结构

插件是一个 `.zip` 压缩包，至少包含：

```
your-plugin/
├── config.json      # 插件配置
├── enter.py         # 入口文件（config.json 中 main 字段指定）
└── xxx.py           # 可选：同目录子模块
```

## config.json

```json
{
  "id": "example",
  "version": "0.0",
  "main": "enter.py",
  "name": { "zh-cn": "示例", "en-us": "Example" },
  "author": "FelixHajimi",
  "description": { "zh-cn": "示例插件", "en-us": "Example plugin" }
}
```

| 字段          | 说明                                                         |
| ------------- | ------------------------------------------------------------ |
| `id`          | 插件唯一标识，用于 API 权限校验                              |
| `version`     | 插件版本                                                     |
| `main`        | 入口文件路径（相对压缩包根目录）                             |
| `name`        | 显示名称，**必须**为多语言映射，且包含主程序当前语言的 key   |
| `author`      | 作者                                                         |
| `description` | 插件描述，可为字符串或多语言映射                             |

`name` 用 `config.name[language]` 取值：缺当前语言 key 会抛 `KeyError`，该插件加载失败。

## language.json（可选）

在包根目录提供 `language.json`，注册插件自己的文案：

```json
{
  "zh-cn": { "title": "示例" },
  "en-us": { "title": "Example" }
}
```

主程序加载时读入，交给 `methods` 事件中的 `Translation` 实例，见 [方法使用](方法使用.md)。

## 子模块（可选）

包根目录下除 `main` 与 `__init__.py` 外的 `.py` 文件会自动注册为 `plugin_<id>.<文件名>` 并执行。插件内导入：

```python
from plugin_example import helper    # 对应 helper.py
```

只支持根目录，子目录中的 `.py` 不会被注册。

## 入口文件

必须定义一个 `Window` 类（继承 `QtWidgets.QWidget`）并实现 `onReceive`：

```python
from PySide6 import QtWidgets, QtCore

class Window(QtWidgets.QWidget):
    def __init__(self):
        super().__init__()
        self.api  # 由主程序注入

    def initUI(self):
        # 插件自行约定，收到 initUI 事件后构建界面
        pass

    @QtCore.Slot(dict)
    def onReceive(self, data: dict):
        if data["type"] == "initUI":
            self.initUI()
```

主程序只要求 `Window` 与 `onReceive`。`initUI` 是推荐约定，由插件自己在收到 `initUI` 事件时调用。

## 打包

手动压缩源码目录，确保 `config.json` 位于压缩包根目录，再放入 `plugin/`。

也可用 `.src/_package.py` 批量打包：把源码目录放进 `plugin/`，运行后生成同名 zip，并删除旧 zip。

## 加载流程

1. 扫描 `plugin/*.zip`。
2. 解析 `config.json`，构造插件配置；字段缺失或类型不符即失败。
3. 注册根目录子模块。
4. 执行 `main` 指向的入口文件，实例化 `Window`。
5. 注入 `Window.api`，把 `Window.onReceive` 连接到主程序信号。
6. 读入 `language.json`（如有），向已加载插件广播 `methods` 事件。
7. 页面加入标签栏，按钮加入侧边栏。

全部插件加载完成后，广播 `setting`，再广播 `initUI`。

任一环节失败会写入 `logs/`，该插件跳过，不影响其他插件。
