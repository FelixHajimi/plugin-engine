# 插件开发

## 插件包结构

插件是一个 `.zip` 压缩包，至少包含：

```
your-plugin/
├── config.json      # 插件配置
└── enter.py         # 入口文件（config.json 中 main 字段指定）
```

## config.json

```json
{
  "id": "example",
  "version": "0.0",
  "main": "enter.py",
  "name": "Example",
  "author": "FelixHajimi",
  "description": "Example plugin"
}
```

| 字段        | 说明                                   |
| ----------- | -------------------------------------- |
| `id`        | 插件唯一标识，用于 API 权限校验        |
| `version`   | 插件版本                               |
| `main`      | 入口文件路径（相对压缩包根目录）       |
| `name`      | 显示名称，支持多语言映射（如 `{"zh-cn": "...", "en-us": "..."}`） |
| `author`    | 作者                                   |
| `description` | 插件描述                             |

可选地，可在包内附带 `language.json`，key 与主程序 `Translation` 语言键（`zh-cn` / `en-us`）一致，用于注册插件自身的语言包。

## 入口文件

入口文件需定义一个 `Window` 类（继承 `QtWidgets.QWidget`），并实现 `initUI` 与 `onReceive`：

```python
from PySide6 import QtWidgets, QtCore

class API:
    def __init__(self, pluginId: str): ...
    def readFile(self, id: str, encoding: str = "utf-8"): ...

class Window(QtWidgets.QWidget):
    def __init__(self):
        super().__init__()
        self.api: API

    def initUI(self):
        # 初始化界面（主程序加载后调用）
        pass

    @QtCore.Slot(dict)
    def onReceive(self, data: dict):
        # 接收主程序广播的数据
        pass
```

## 打包

将插件源码目录压缩为 zip，确保 `config.json` 位于压缩包根目录，然后放入 `plugin/` 目录。

## 加载流程

1. 主程序扫描 `plugin/*.zip`。
2. 读取 `config.json`，校验必需字段。
3. 读取 `main` 指向的入口文件并执行，实例化 `Window`。
4. 注入 `Window.api`。
5. 将 `Window.onReceive` 连接到主程序信号。
6. 若包内含 `language.json`，广播 `languageMap` 事件。
7. 将插件页面加入标签栏，按钮加入侧边栏。

任一环节失败会记录到 `logs/`，该插件跳过加载。
