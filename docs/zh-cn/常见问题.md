# 常见问题

## 插件没有加载 / 页面没出现

检查 `logs/` 下的日志，常见原因：

- zip 损坏或不是有效压缩包。
- 包内缺少 `config.json` 或入口文件。
- `config.json` 字段缺失或类型不符（如 `main` 不存在）。
- 入口文件语法错误，或未定义 `Window` / `onReceive`。

主程序会记录具体错误并跳过该插件，不影响其他插件加载。

## 插件加载失败后怎么排查

1. 打开 `logs/last.log` 或最新的时间戳日志。
2. 查看 `ERROR` 级别的记录，定位到对应插件。
3. 根据错误信息修正 zip 内容后重新启动。

## readFile 一直返回 None

可能原因：

- 数据文件不存在或 JSON 损坏。
- `id` 含 `../` 或 `..\`（被路径穿越防护拦截）。
- 本插件 id 不在 `meta.allowRead` 中，也非 `"*"`。

## writeFile 写不进去

可能原因：

- 本插件 id 不在 `meta.allowWrite` 中，也非 `"*"`（无写权限）。
- 写入对象不可序列化。
- 文件系统错误。

若写入中途失败，临时文件可能残留在 `data/temp/`，属正常现象，可安全清理。

## 怎么让插件显示成中文

- 插件 `name` 字段支持多语言映射：`{"zh-cn": "示例", "en-us": "Example"}`。
- 主程序语言由设置页的 `语言` 项决定。

## 如何设置启动时显示的页面

在设置页的 `启动界面` 中输入目标页面的名称（与标签栏页名一致）。留空则显示第一个页面。

## 数据文件默认在哪里

`.src/data/` 目录，文件名为 `data/<id>.json`。`data/temp/` 是原子写入用的临时目录。

## 插件需要额外 Python 库怎么办

插件入口文件内自行 `import` 所需库。若该库未安装，插件会加载失败并写入日志，请先 `pip install` 对应依赖。

## 为什么 .gitignore 排除了很多文件

`.gitignore` 排除了虚拟环境、`logs/`、`__pycache__` 以及下划线开头的内部文件（`_*`）。这些属于私有内容，不对外发布。
