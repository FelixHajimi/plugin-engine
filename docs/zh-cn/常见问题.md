# 常见问题

## 插件没有加载 / 页面没出现

检查 `logs/` 下的日志，常见原因：

- zip 损坏或不是有效压缩包。
- 包内缺少 `config.json` 或入口文件。
- `config.json` 缺字段或类型不符，例如 `name` 不是多语言映射。
- `name` 缺少主程序当前语言的 key（抛 `KeyError`）。
- 入口文件语法错误，或未定义 `Window` / `onReceive`。

主程序记录具体错误并跳过该插件，不影响其他插件。

## 怎么排查加载失败

1. 打开 `logs/last.log` 或最新的时间戳日志。
2. 查看 `ERROR` 记录，定位到对应插件。
3. 修正 zip 内容后重新启动。

## readFile 一直返回 None

- 数据文件不存在或 JSON 损坏。
- `id` 含 `../` 或 `..\`（被路径穿越防护拦截）。
- 本插件 id 不在 `meta.allowRead` 中，也非 `"*"`。

## writeFile 写不进去

- 文件不存在：`writeFile` 不会新建文件。
- 本插件 id 不在 `meta.allowWrite` 中，也非 `"*"`。
- 写入对象不可序列化。
- 文件系统错误。

写入中断可能在 `data/temp/` 残留临时文件，属正常现象，可安全清理。

## onReceive 收到多次 methods

信号是广播，每个插件加载时都会触发一次，先加载的插件会收到后加载插件的事件。按 `data["pluginId"] == self.api.pluginId` 过滤。

## showMessage 没有显示

- 调用早于界面初始化，消息被丢弃（日志有 warning）。
- `duration` 为 0 时不会自动消失，并非没弹出。
- `level` 越界会被截断到 0-3，颜色可能与预期不同。

## addUpdateFunc 没有执行

- `duration` 单位是秒，首次执行在注册后 `duration` 秒。
- 回调抛出异常会中断本次调用，请在回调内自行 `try`。

## 子模块导入失败

包根目录的 `.py` 注册为 `plugin_<id>.<文件名>`，必须用完整名导入：

```python
from plugin_example import helper
```

`import helper` 或子目录中的模块不可用。

## 怎么让插件显示成中文

- `name` 字段必须是多语言映射：`{"zh-cn": "示例", "en-us": "Example"}`。
- 主程序语言由设置页的「语言」项决定。
- 插件自身文案用 `language.json` + `translation`，见 [方法使用](方法使用.md)。

## 如何设置启动时显示的页面

在设置页「启动界面」中填目标页名，需与标签栏页名完全一致（即插件 `config.name` 当前语言的值）。填错或留空时不切换，显示第一个页面。

## 数据文件默认在哪里

`.src/data/` 目录，文件为 `data/<id>.json`。`data/temp/` 是原子写入的临时目录。

## 插件需要额外 Python 库怎么办

在入口文件内 `import`。库未安装会导致插件加载失败并写入日志，请先 `pip install`。
