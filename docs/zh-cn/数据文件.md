# 数据文件格式

数据文件存放在 `data/` 目录，为带权限元信息的 JSON。

## 结构

```json
{
  "meta": {
    "description": "Example data file",
    "allowRead": ["*"],
    "allowWrite": ["*"]
  },
  "content": { "main": "data" }
}
```

## 字段说明

| 字段               | 类型     | 说明                                   |
| ------------------ | -------- | -------------------------------------- |
| `meta.description` | string   | 文件描述                               |
| `meta.allowRead`   | string[] | 允许读的插件 id 列表，`"*"` 表示全部   |
| `meta.allowWrite`  | string[] | 允许写的插件 id 列表，`"*"` 表示全部   |
| `content`          | any      | 业务数据，插件通过 API 读写此字段      |

## 权限规则

- 插件 id 在 `allowRead` / `allowWrite` 中，或存在 `"*"`，则拥有对应权限。
- 无权限时 `readFile` / `writeFile` 返回 `None` 并记录日志。

## 全局设置文件

`data/setting.json` 是特殊的设置文件，`content` 保存各设置项当前值：

```json
{
  "content": {
    "general.language": {
      "type": "currentText",
      "value": "zh-cn"
    }
  }
}
```

设置项由[设置页](../项目结构.md)声明并自动保存。
