# 数据文件格式

数据文件存放在 `data/` 目录，为带权限元信息的 JSON。

## 结构

```json
{
  "meta": {
    "description": "Example data file",
    "allowRead": ["*"],
    "allowWrite": ["*"]
  },
  "content": { "main": "data" }
}
```

## 字段说明

| 字段               | 类型       | 说明                                   |
| ------------------ | ---------- | -------------------------------------- |
| `meta.description` | string / 多语言对象 | 文件描述，仅作说明，不参与权限判断 |
| `meta.allowRead`   | string[]   | 允许读的插件 id，`"*"` 表示全部        |
| `meta.allowWrite`  | string[]   | 允许写的插件 id，`"*"` 表示全部        |
| `content`          | any        | 业务数据，插件通过 API 读写此字段      |

## 读取与写入

- `readFile(id)` 返回 `content`。
- `writeFile(id, obj)` 把 `obj` 替换到 `content` 并保存；必须先存在该文件。
- 写入走 `data/temp/` 临时文件再 `os.replace`，中断不会损坏原文件。
- 重启后 `data/temp/` 可能残留临时文件，可安全清理。

## 权限规则

- 插件 id 在对应列表中，或列表含 `"*"`，即拥有权限。
- 无权限时 `readFile` / `writeFile` 返回 `None` 并记录日志。

## 全局设置文件

`data/setting.json` 是特殊文件，`meta.allowRead` 为 `["*"]`、`allowWrite` 为空，即插件可读、不可写。`content` 保存各设置项当前值：

```json
{
  "content": {
    "general.language": { "type": "currentText", "value": "zh-cn" },
    "general.firstPage": { "type": "text", "value": "" }
  }
}
```

设置页每秒自动保存一次，同样走 `data/temp/` 原子写入。设置项的声明方式见[设置页](设置页.md)。
