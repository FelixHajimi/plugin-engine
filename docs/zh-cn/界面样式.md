# 界面样式

主程序通过 `app.setStyleSheet` 提供全局样式，插件给控件设置 `class` / `type` 属性即可套用，无需自己写 QSS。

## 按钮

```python
btn = QtWidgets.QPushButton("确定")
btn.setProperty("class", "button")          # 必填：基础按钮
btn.setProperty("type", "primary")          # 可选：primary / danger
```

| 属性                       | 效果                       |
| -------------------------- | -------------------------- |
| `class=button`             | 圆角、浅灰底、内边距       |
| `class=button` `type=primary` | 蓝底白字，带 hover / pressed |
| `class=button` `type=danger`  | 红字淡红底                 |
| `:disabled`                | 置灰                       |

## 文本

```python
label = QtWidgets.QLabel("标题")
label.setProperty("class", "text")
label.setProperty("type", "title")
```

| `type`     | 字号 / 颜色               |
| ---------- | ------------------------- |
| `title`    | 18px、加粗、`#1F1F1F`     |
| `subtitle` | 14px、`#666666`           |
| `body`     | 13px、`#333333`           |
| `hint`     | 12px、`#999999`           |

## 输入与容器

| 属性             | 效果                             |
| ---------------- | -------------------------------- |
| `class=input`    | 输入类控件：圆角边框，聚焦蓝边   |
| `class=card`     | 卡片容器：白底、浅边框、圆角     |

## 侧边栏

`group=text` 用于侧边栏的纯文本项（无背景、16px），对应 `SidebarButtonData(group="text")`。

## 动态修改后刷新

运行时改 `class` / `type` 后需重新应用样式：

```python
btn.setProperty("type", "danger")
btn.style().unpolish(btn)
btn.style().polish(btn)
```

## 消息卡片

浮动消息请用 `api.showMessage`，已内置配色与动效，见[插件 API](插件API.md)。
