# 设置页

设置页由 `settingPage.py` 内的 `self.data` 声明生成，不需要手写控件。改完声明后重启生效。

## 声明结构

```python
self.data = {
    "_type": "group",
    "General": {
        "_type": "group",
        "_label": {"zh-cn": "常规", "en-us": "General"},
        "FirstPage": {
            "_type": "item",
            "_id": "general.firstPage",
            "_valueType": "lineedit",
            "_default": {"zh-cn": "", "en-us": ""},
            "_placeholder": {"zh-cn": "启动界面", "en-us": "FirstPage"},
            "_label": {"zh-cn": "启动界面", "en-us": "FirstPage"},
        },
    },
}
```

- 以 `_` 开头的键是属性，其余键是分组/设置项，可任意嵌套。
- `group` 渲染为 `QGroupBox`，`item` 渲染为一行「标签 + 控件」。
- `_id` 是设置项唯一 id，同时作为控件 `objectName` 与 `setting.json` 的键。

## 控件类型

| `_valueType`  | 控件          | 额外字段                                   |
| ------------- | ------------- | ------------------------------------------ |
| `language`    | 下拉框        | `_valueList`（字符串数组）、`_default`（字符串） |
| `combobox`    | 下拉框        | `_valueList`、`_default`（均多语言映射）   |
| `checkbox`    | 复选框        | `_default`（多语言布尔）                   |
| `slider`      | 滑条          | `_min`、`_max`、`_default`、`_prefix`、`_suffix` |
| `spinbox`     | 数字框        | 同 `slider`                                |
| `lineedit`    | 输入框        | `_default`、`_placeholder`（多语言）       |
| `filepicker`  | 输入框 + 浏览 | `_default`（字符串）、`_filter`（多语言过滤串） |
| `colorpicker` | 输入框 + 取色 | `_default`（颜色字符串）                   |

`slider` / `spinbox` 会在控件右侧显示「前缀 + 当前值 + 后缀 (min-max)」。

## 保存格式

每秒自动保存一次，写入 `setting.json` 的 `content`：

| 控件类型                   | 存为                                  |
| -------------------------- | ------------------------------------- |
| `language`、`combobox`     | `{"type": "currentText", "value": ...}` |
| `checkbox`                 | `{"type": "checked", "value": ...}`     |
| `slider`、`spinbox`        | `{"type": "value", "value": ...}`       |
| `lineedit`、`filepicker`、`colorpicker` | `{"type": "text", "value": ...}` |

保存经 `data/temp/setting.json` 原子替换，中断不会损坏原文件。

## 内置设置项

| id                | 类型   | 作用                                     |
| ----------------- | ------ | ---------------------------------------- |
| `general.language`| 下拉框 | 界面语言，`zh-cn` / `en-us`              |
| `general.firstPage` | 输入框 | 启动页名，匹配标签栏页名；空则显示第一页 |

## 限制

设置页目前由主程序固定声明，插件不能向其中添加设置项。
