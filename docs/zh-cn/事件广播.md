# 事件广播

主程序启动后通过 Qt 信号向所有插件广播事件。插件在 `Window.onReceive(data)` 中接收，用 `data["type"]` 区分类型。

## 事件类型

| type          | content                          | 说明                 |
| ------------- | -------------------------------- | -------------------- |
| `languageMap` | 插件 `language.json` 内容        | 注册插件语言包       |
| `setting`     | 主程序 `setting.json` 的 content | 下发全局设置         |
| `methods`     | `{ "translation": Translation }` | 暴露主程序工具类     |
| `initUI`      | —                                | 通知插件初始化界面   |

## 接收示例

```python
@QtCore.Slot(dict)
def onReceive(self, data: dict):
    if data["type"] == "initUI":
        self.initUI()
    elif data["type"] == "setting":
        # 使用全局设置
        pass
```

## 说明

- `initUI` 是插件初始化的关键事件，通常在收到后构建界面。
- `languageMap` 仅在插件包内含 `language.json` 时广播。
