# 事件广播

主程序通过 Qt 信号向插件广播事件。插件在 `Window.onReceive(data)` 中接收，用 `data["type"]` 区分。

## 事件类型

| type      | 触发时机                     | content                          | 说明                     |
| --------- | ---------------------------- | -------------------------------- | ------------------------ |
| `methods` | 每个插件加载完成时           | `{ "translation": Translation }` | 暴露工具类，见 [方法使用](方法使用.md) |
| `setting` | 全部插件加载完成后           | `setting.json` 的 `content`      | 下发全局设置             |
| `initUI`  | `setting` 之后，一次         | —                                | 通知插件初始化界面       |

`methods` 事件额外带顶层字段 `pluginId`，标识这次广播属于哪个插件。

## methods 的广播特性

信号是广播：插件加载时会 `emit` 一次，**所有已连接的插件都会收到**。因此在插件 B 加载时，先加载的插件 A 也会再收到一次 `methods`，其 `translation` 属于 B、`pluginId` 是 B。

插件应按 `pluginId` 过滤，只保存属于自己的那一份：

```python
if data["type"] == "methods" and data["pluginId"] == self.api.pluginId:
    self.translation = data["content"]["translation"]
```

## setting 的 content

`content` 以设置项 id 为键，值为 `{"type": ..., "value": ...}`：

```json
{
  "general.language": { "type": "currentText", "value": "zh-cn" },
  "general.firstPage": { "type": "text", "value": "" }
}
```

取当前语言：`data["content"]["general.language"]["value"]`。

## 接收示例

```python
@QtCore.Slot(dict)
def onReceive(self, data: dict):
    if data["type"] == "methods":
        if data["pluginId"] == self.api.pluginId:
            self.tran = data["content"]["translation"]
    elif data["type"] == "setting":
        self.setting = data["content"]
    elif data["type"] == "initUI":
        self.initUI()
```
