# 项目结构

## 仓库目录

```
plugin-engine/
├── .src/                    # 主程序源码
│   ├── main.py              # 入口：插件加载、信号分发、侧边栏与页面架构
│   └── settingPage.py       # 声明式设置页（自动生成表单 + 自动保存）
├── docs/
│   ├── zh-CN/               # 中文文档
│   └── en-US/               # 英文文档
├── Example/
│   ├── Plugin/example/      # 示例插件源码 + example.zip
│   └── Data/example.json    # 数据文件格式示例
├── LICENSE
├── README.md
└── README.zh-CN.md
```

## 运行时目录

首次运行 `main.py` 自动创建（位于 `.src/` 下）：

```
.src/
├── plugin/          # 插件目录，放入 *.zip
├── data/
│   ├── setting.json # 全局设置
│   └── temp/        # 原子写入临时目录
└── logs/            # 日志（时间戳文件 + last.log）
```

## 各模块职责

| 文件/目录       | 职责                                         |
| --------------- | -------------------------------------------- |
| `main.py`       | 应用入口、插件加载、信号广播、UI 组装        |
| `settingPage.py`| 声明式设置页：根据配置生成表单并自动保存     |
| `plugin/`       | 存放待加载的插件 zip                         |
| `data/`         | 数据文件，供插件通过 API 读写                |
| `logs/`         | 运行日志                                     |
