# 项目结构

## 仓库目录

```
plugin-engine/
├── .src/                    # 主程序源码
│   ├── main.py              # 入口：插件加载、信号分发、消息卡片、全局样式
│   ├── settingPage.py       # 声明式设置页（自动生成表单 + 自动保存）
│   ├── _package.py          # 打包脚本：把 plugin/ 下目录打成 zip
│   └── _test.py             # 本地试验备份，不参与运行
├── docs/
│   ├── zh-cn/               # 中文文档
│   └── en-us/               # 英文文档
├── Example/
│   ├── Plugin/example/      # 示例插件源码 + example.zip
│   └── Data/example.json    # 数据文件格式示例
├── LICENSE
├── README.md
└── README.zh-cn.md
```

## 运行时目录

首次运行 `main.py` 自动创建（位于 `.src/` 下）：

```
.src/
├── plugin/          # 插件目录，放入 *.zip 与待打包的源码目录
├── data/
│   ├── setting.json # 全局设置
│   └── temp/        # 原子写入临时目录
└── logs/            # 日志
```

## 日志

- 每次启动生成 `logs/<YYYY-MM-DD-HH-MM>.log`，只记录 WARN 及以上。
- `logs/last.log` 记录 DEBUG 及以上，**每次启动重写**。
- `logs/` 下最多保留 10 个文件（含 `last.log`），超出时删除最早的。

## 各模块职责

| 文件 / 目录     | 职责                                             |
| --------------- | ------------------------------------------------ |
| `main.py`       | 应用入口、插件加载、信号广播、消息卡片、全局样式 |
| `settingPage.py`| 声明式设置页：按声明生成表单并自动保存           |
| `_package.py`   | 打包脚本：删除旧 zip，把 `plugin/` 下目录重新打包 |
| `plugin/`       | 存放插件 zip                                     |
| `data/`         | 数据文件，供插件通过 API 读写                    |
| `logs/`         | 运行日志                                         |
