# methods 事件：主程序工具类

`methods` 事件向插件下发工具类，事件结构：

```json
{
  "type": "methods",
  "pluginId": "example",
  "content": { "translation": Translation }
}
```

`pluginId` 标识本次广播属于哪个插件，插件应按它过滤。

## Translation 翻译类

### 接口定义

```python
class Translation:
    languageMap: typing.Dict[str, typing.Dict[str, typing.Any]]
    language: str
    def __init__(self, languageMap: dict, language: str) -> None: ...
    def exec(self, key: str, fallback: str = "") -> typing.Any: ...
```

`languageMap` 是本插件 `language.json` 的内容，`language` 是主程序当前语言（如 `zh-cn`）。

### 要点

1. `translation` 为**已实例化对象**，直接调用 `exec`，无需再次实例化。
2. `exec` 查找规则：优先当前语言，缺失回退 `en-us`，仍缺失返回 `fallback`。
3. 返回值是 `Any`：语言包里的值可以是字符串、列表等，不一定为 `str`。
4. 插件没有 `language.json` 时 `languageMap` 沿用上一次读入的内容（空或前一个插件的语言包），`exec` 可能取到别的插件的文案。
5. `methods` 是广播，先加载的插件会收到其它插件的 `methods`，用 `pluginId` 过滤。
