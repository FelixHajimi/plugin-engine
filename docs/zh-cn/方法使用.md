# methods 事件：主程序工具类

`methods` 事件向插件暴露工具

```json
{ "translation": Translation }
```

## Translation 翻译类

### 接口定义

```python
class Translation:
    languageMap: dict[str, dict[str, str]]
    language: str
    def __init__(self, languageMap: dict[str, dict[str, str]], language: str): ...
    def exec(self, key: str, fallback: str = "") -> str: ...
```

### 要点

1. `translation` 为**已实例化对象**，直接调用 `exec`，无需再次实例化
2. `exec` 查找规则：优先当前语言，缺失自动回退 `en-us`，仍缺失返回 `fallback`
3. `content` 字典后续会新增工具，插件读取时做好判空，不要假设固定字段
